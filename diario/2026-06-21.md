# Diario de Bordo - 2026-06-21

## Sessoes do Dia

- **Restauracao Internet Cohen (M70q) — Queda de Energia:** Queda de energia no condominio as 13:08h. Apos retorno, Cohen ficou sem internet. Diagnostico via SSH revelou nova causa raiz: Tailscale configurou `~.` (catch-all DNS) no systemd-resolved, e o resolver do tailnet (100.67.12.86) nao respondia consultas externas apos reboot.
- **Correcao:** `sudo resolvectl domain tailscale0 "~wagtail-snapper.ts.net"` — removeu `~.` do escopo DNS do Tailscale, mantendo MagicDNS apenas para dominios `*.ts.net`. DNS direto na wlo1 (1.1.1.1, 8.8.8.8) voltou a funcionar.
- **Verificacao:** Todos os providers alcancaveis (DeepSeek HTTP 401, OpenAI HTTP 421, NVIDIA HTTP 404). MagicDNS intacto (`homelab.wagtail-snapper.ts.net` resolvendo em 1ms).

## Decisoes e Aprendizados

- `resolvectl domain` preferido em vez de `tailscale set --accept-dns=false` para manter MagicDNS
- Correcao temporaria (nao persiste a reboot) — Christian vai avaliar fix permanente
